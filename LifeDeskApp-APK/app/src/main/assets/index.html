装到华为手机主屏幕

数据全程存在你手机本地浏览器，不上传、不外泄。

  1. 把 life-workspace.html 传到手机：华为分享 / USB / 微信「文件传输助手」/ 邮箱附件 / 百度网盘 都可以。
  2. 在手机上用 华为浏览器 打开它：文件管理找到文件 → 更多 → 用浏览器打开；或在华为浏览器里直接打开本地文件。
  3. 点浏览器右下角「菜单」（⋮ 或 ≡）→ 选 「添加到主屏幕」 → 起个名字（如「生活台」）→ 确定。
  4. 回到桌面就有图标了，点开即全屏使用，和 APP 一样，数据自动保存在手机里。

⚠️ 一定要用「华为浏览器」打开再添加；用微信 / QQ 内置浏览器打开无法加到主屏幕。

⚠️ 数据读取异常

部分本地数据已损坏，无法解析。你的数据仍在浏览器中，可导出损坏备份交由技术支持，或清除后恢复出厂示例。
